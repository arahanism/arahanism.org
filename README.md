# Arahanism Knowledge Base Archive

## Overview
This repository contains the official text corpus and structural data export from **[arahanism.org](https://arahanism.org/)**, a digital platform and scholarly repository dedicated to the original liberation teachings of Gautama the Supreme Arahant. 

Rooted in the early Theravāda textual tradition, Arahanism emphasizes literal philological precision, etymological accuracy in Pāḷi terminology, and the restoration of the ancient path of worldly renunciation, leading through *Sīla, Samādhi, and Paññā* toward complete release from worldly bondage (*loka*) and entry into the Deathless realm (*Nibbāna-dhātu*).

---

## Corpus Contents & Directory Structure

* **`wordpress_export.xml`**: The raw WordPress WXR export file containing complete site posts, pages, categories, and structural metadata.
* **`dataset.jsonl`**: A clean, parsed dataset line-by-line in JSON format, optimized for Retrieval-Augmented Generation (RAG), LLM fine-tuning, and machine-learning ingestion pipelines.
* **`markdown_files/`**: Individual Markdown (`.md`) files for every published essay, translation guide, and doctrinal explanation for human readability and static-site archiving.

---

## Core Themes & Terminology Framework
This knowledge base preserves specific classical terminology to maintain absolute doctrinal and philosophical fidelity:
* **Nibbāna-Dhātu:** Understood strictly as an ultimate, transcendent realm—the exit point from *saṃsāra* via the fourth jhāna gateway.
* **Rāga, Dosa, Moha:** The fundamental roots of bondage (preferred over generic modern psychological euphemisms).
* **Bhikkhu / Brahmacariya:** Precision terms maintained for monastic discipline and the holy life.
* **Anatta:** Interpreted through the lens of worldly phenomena (*loka*) that the *citta* ultimately disenchants, leaves behind, and transcends.
